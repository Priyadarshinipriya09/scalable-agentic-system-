# Scalable Agentic System

## Project Overview

This project is a Python prototype of a scalable agentic system.

The system takes a user's natural-language request, searches for relevant
information and tools, selects the correct tool, executes it, and returns
the result.

## Main Features

- Natural-language requests
- 500 registered tools
- Tool Registry
- Tool Routing
- RAG-style search
- System Search
- State Management
- Tool Execution
- Basic Error Handling
